# Cloudora SOC Phase 4 Dataset

Synthetic, lab-safe telemetry for:
**Executive Account Takeover Investigation & Detection Engineering using Splunk**

- Sign-in telemetry: cloudora_signin_logs.csv
- Audit telemetry: cloudora_audit_logs.csv
- Period: 2026-08-04 through 2026-08-11 UTC
- Sign-in events: approximately 1,480
- Audit events: approximately 160+
- IPs use documentation/reserved ranges.
- No real credentials, customer information, or external attack activity are used.

The dataset intentionally mixes normal and suspicious activity. Investigation conclusions
must be reached from evidence rather than from labels in the data.
